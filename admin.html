      Questions 0

      This is the password for this editor — separate from the questions below, which are what visitors answer to see the site.

      How it works. A visitor gets one question at random and can ask for a different one. Answers are compared loosely — capitals, spaces, punctuation and accents are all ignored, so Arnold-Palmer, arnold palmer and ARNOLDPALMER are the same answer. Word order still matters.

      Answers are stored as a SHA-256 hash, never as text — which also means leaving an answer box blank keeps the existing answer. Type a new one only when you want to change it.

      This is a doorlock, not a vault. Served as plain files, the check happens in the visitor's browser and a determined person could read data.json directly. Run python3 server.py --gate to have the server refuse the archive until the question is answered.
